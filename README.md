# HalleyX Dashboard

## 📌 Project Overview

HalleyX Dashboard is a full-stack dashboard application developed using React for the frontend and Node.js for the backend. It provides an interactive dashboard interface with API integration and deployment on Vercel.

---

## 🚀 Features

- Responsive dashboard
- API integration
- Frontend and Backend architecture
- Interactive UI
- Vercel deployment

---

## 🛠 Technologies Used

Frontend
- React
- JavaScript
- HTML
- CSS

Backend
- Node.js
- Express.js

Deployment
- Vercel
